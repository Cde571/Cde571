## PROFILE

I am Cristian Echeverry, a full-stack developer focused on building digital products with strong visual identity, solid frontend architecture, and practical backend logic.

My work combines:

- interactive interfaces
- professional UI systems
- scalable application structure
- product-oriented development

I enjoy creating experiences that feel visually distinct without losing clarity, performance, or usability.

<summary><b>How I actually use it</b></summary>

<br />

```text
Frontend      -> Astro and React with TypeScript. Component-driven,
                 typed props, no framework soup.
Styling       -> Hand-written CSS systems. Design tokens over utility
                 sprawl when the interface has a strong identity.
Backend       -> Node.js with REST APIs. MongoDB when the shape of the
                 data is still moving.
Vision / ML   -> Python with OpenCV and PyTorch for detection,
                 segmentation and super-resolution work.
Tooling       -> Git, Docker, Vercel. Figma before code when the
                 interface carries the product.
```
